# Academic website

Built with [Quarto](https://quarto.org) and hosted free on GitHub Pages.

## Editing

- `index.qmd`: About page (bio, interests, education)
- `research.qmd`: publications and talks
- `teaching.qmd`: courses
- `cv.qmd`: shows `files/cv.pdf`
- `profile.jpg`: your photo (add one with this exact name)
- `_quarto.yml`: site title, menu, theme

Edit the files, then commit and push. GitHub rebuilds the site in about a minute
(watch progress under the repository's **Actions** tab).
